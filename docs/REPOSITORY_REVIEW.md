# リポジトリへのアップロード・公開前確認

確認日：2026-10-03

## 判定と対象

今回Gitに登録するソース・設定テンプレート・素材・ドキュメントの範囲では、非公開GitHubリポジトリへのアップロードを妨げる秘密情報・個人の実機データは見つかりませんでした。新規の履歴として登録し、既存のローカル作業履歴やログは含めません。

初回の非公開アップロード後、所有者の指示で公開へ切り替えるため再確認しました。公開対象は、この確認済みの初回コミットとREADMEの技術バッジ・使用技術表などの文書更新です。初回コミットにも個人パスの除去と署名・個人設定の除外が反映されています。READMEのバッジはShields.ioの静的な技術名表示で、トークンや個人の識別情報をURLに含めていません。

これはすべての機密情報の不在を保証する監査ではありません。文字列検査、設定内容の確認、素材の目視・メタデータ確認を組み合わせた今回のアップロード対象のレビューです。追加ファイル、公開範囲の変更、配布メタデータの実値入力後は再確認してください。

## 除去・除外したもの

| 対象 | 対応 |
| --- | --- |
| 画像生成記録の端末内絶対パス | 削除。生成元、日付、プロンプト、プロジェクト内の素材パスを維持 |
| 開発者登録についての個人の回答 | 配布チームの設定状態という一般的な記述に変更 |
| Xcodeの個人用状態・設定 | `xcuserdata`、`xcuserstate`、`.swiftpm`をGit対象外に設定 |
| 秘密鍵・証明書・署名済み出力 | `.p8`、`.p12`、証明書、プロビジョニング、Archive、IPAなどを除外 |
| 端末内の記録・写真 | 状態JSON、Screen Time状態、端末データ書き出し、Photosディレクトリを除外 |
| ローカル環境・ログ | `.env`、ビルド出力、ログ、ローカル署名設定を除外 |
| コミットのメール | GitHubのnoreplyアドレスを使用。個人メールを使用しない |

## 確認した内容

- ステージされたファイルを対象に、秘密鍵、代表的なAPI／GitHubトークン、AWSアクセスキー、メールアドレス、個人のホームパス、実機UDID、設定済みの開発チームIDを検査。該当なし。
- 本体と3拡張の共有XcodeプロジェクトはTeam IDが空。配布用の氏名・メール・電話・Team IDなども未入力のテンプレートであることを確認。
- 除外対象のXcode個人設定や実機保存データがステージされていないことを確認。
- PNGのメタデータを確認。検査したEXIFは色空間・画像寸法で、GPSや作者・個人パスは見つからない。
- 5枚の検証スクリーンショットを目視。アプリの検証用タスク・実績が表示され、顔・個人メール・実機の端末名などは見つからない。
- 演出動画を1秒間隔でフレーム確認。検証用の完了演出が映り、動画に音声トラックはない。動画メタデータはエンコーダー・形式情報。
- アプリ同梱の3効果音が、音声録音を使わない合成スクリプトから再生成したWAVと完全一致することを確認。
- 画像素材は生成プロンプトを記録したアイコン・メダル・背景。外部の3Dモデルは含まれない。

## 今後のアップロード前

```sh
git add <アップロードするファイル>
python3 scripts/check_repository.py
git diff --cached --check
git diff --cached --stat
```

`check_repository.py`はGitのステージ内容を読み、検出値そのものは表示せず、ファイルと検出種別を報告します。バイナリ画像・音声・動画の内容は判定しないため、別に目視・メタデータ確認を行ってください。`.gitignore`はすでに追跡済みのファイルや過去コミットから情報を取り除く機能ではありません。

GitHubの非公開保存はTestFlightやApp Storeへの配布許可を意味しません。一般公開・再配布時は、ライセンス、素材の利用条件、公開プライバシーポリシー、必要なAppleの権限を別途確認してください。
